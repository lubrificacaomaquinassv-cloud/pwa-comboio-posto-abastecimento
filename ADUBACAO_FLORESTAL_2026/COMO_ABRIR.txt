COMO ABRIR O PAINEL
===================

ONDE ESTÁ NO SEU PC
-------------------
Pasta do projeto (onde você baixou o GitHub):

   C:\pwa-comboio-posto-abastecimento\ADUBACAO_FLORESTAL_2026\

Se a pasta estiver em outro disco, use o mesmo caminho
onde você guarda o projeto — o importante é entrar
dentro da pasta ADUBACAO_FLORESTAL_2026.


COMO ABRIR (escolha UMA opção)
------------------------------

OPÇÃO A — Mais fácil (duplo clique)
   Abra a pasta acima no Explorer e dê duplo clique em:

   RODAR_PAINEL.bat

   O navegador abre sozinho em http://localhost:8501


OPÇÃO B — Atalho na pasta pai
   Duplo clique em (pasta acima):

   C:\pwa-comboio-posto-abastecimento\ABRIR PAINEL ADUBACAO.bat


OPÇÃO C — Só se pediram atualização
   Abra o Prompt na pasta C:\pwa-comboio-posto-abastecimento
   e digite:  git pull
   Depois use a Opção A.


O QUE NÃO É O PAINEL
--------------------
   Link do GitHub no navegador = só código, não abre o painel.
   O painel só abre pelo .bat no seu PC.
